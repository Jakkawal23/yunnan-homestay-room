# หลังบ้าน (เว็บสำหรับทีมงาน)

หน้าเว็บสำหรับ **ดู เพิ่ม แก้ไข การจอง** ผ่านมือถือ โดยไม่ต้องเปิด Google Sheet
ข้อมูลอ่าน/เขียนที่ Google Sheet ตัวเดียวกัน **กรอกในเว็บหรือในชีตก็ได้ เห็นข้อมูลเดียวกัน**

| | |
|---|---|
| ไฟล์ | [`apps-script/Admin.html`](../apps-script/Admin.html) (หน้าเว็บ) + ฟังก์ชันหลังบ้านใน [`apps-script/Code.gs`](../apps-script/Code.gs) |
| อยู่ที่ไหน | Google Apps Script (deploy ตัวเดียวกับ API ห้องว่าง) |
| ลิงก์ | ลิงก์ `/exec` + `?page=admin` เช่น `https://script.google.com/macros/s/AKfy..../exec?page=admin` |
| เข้าใช้ | รหัสเข้าหลังบ้าน (แท็บ **ตั้งค่า** ในชีต แถว "รหัสเข้าหลังบ้าน" ค่าเริ่มต้น `1234`) |

> **ห้ามลิงก์หน้าหลังบ้านจากเว็บลูกค้า หรือใส่ใน Rich menu**
> ส่งลิงก์ให้ทีมงานทางแชทส่วนตัว แล้วกด "เพิ่มไปที่หน้าจอโฮม" ในมือถือ จะเปิดได้เหมือนแอป

## ติดตั้ง

ทำหลังจากสร้างชีตและวาง `Code.gs` แล้ว ([google-sheet.md](google-sheet.md))

1. ใน Apps Script กด **+** ข้างคำว่า Files → **HTML** → ตั้งชื่อ **`Admin`** (ไม่ต้องพิมพ์ .html)
2. ลบเนื้อหาเดิม แล้ววางทั้งหมดจาก `apps-script/Admin.html` → บันทึก
3. วาง `Code.gs` เวอร์ชันล่าสุดทับด้วย (มีฟังก์ชันหลังบ้านเพิ่ม)
4. รัน `setup` อีกครั้ง 1 รอบ (จะเพิ่มแถว "รหัสเข้าหลังบ้าน" ในแท็บตั้งค่าให้ ข้อมูลเดิมไม่หาย)
5. **เปลี่ยนรหัส** ในแท็บตั้งค่า จาก `1234` เป็นรหัสใหม่ (ตัวเลขหรือตัวอักษรก็ได้)
6. Deploy
   - ถ้ายังไม่เคย deploy: Deploy → New deployment → Web app → Execute as **Me** · Who has access **Anyone**
   - ถ้า deploy API ห้องว่างไปแล้ว: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (ลิงก์เดิม)
7. เปิดลิงก์ `/exec?page=admin` ในมือถือ ใส่รหัส → เลือกชื่อตัวเอง → ใช้งานได้
   หรือในชีตกดเมนู **🏠 โฮมสเตย์ → เปิดหลังบ้าน (เว็บ)** จะแสดงลิงก์ให้

## ใช้งาน

### เข้าสู่ระบบ
- ใส่รหัส → ติ๊ก **"จำรหัสในเครื่องนี้"** ได้ถ้าเป็นมือถือส่วนตัว (ไม่ติ๊ก = ต้องใส่ใหม่เมื่อปิดเบราว์เซอร์)
- เลือก **"คุณคือใคร"** (วาฬ / แบม / เหมยๆ) ชื่อนี้จะใส่ในช่องผู้บันทึกให้อัตโนมัติ เปลี่ยนได้ที่ปุ่มชื่อมุมขวาบน
- ใส่รหัสผิด 10 ครั้ง ระบบล็อก 10 นาที

### หน้าปฏิทิน
- กล่อง **วันนี้**: พักอยู่กี่ห้อง ใครเข้า/ออกวันนี้ และยอดค้างจ่ายของคนนั้น (แตะเพื่อดูรายละเอียด)
- ตาราง **วัน × ห้อง** ทั้งเดือน (‹ › เปลี่ยนเดือน)
  - แถบสี = มีคนจอง ชื่อขึ้นที่วันเช็คอิน · เหลือง รอมัดจำ · ส้ม มัดจำแล้ว · ฟ้า ชำระครบ · เทา ปิดห้อง · แดง จองซ้อน
  - แตะแถบสี → ดูรายละเอียด
  - แตะช่อง **+** → จองใหม่ (เลือกห้องและวันให้แล้ว 1 คืน)

### หน้ารายการจอง
- ค้นหาด้วย ชื่อ / เบอร์ / เลขที่จอง / หมายเหตุ
- ตัวกรอง: **กำลังจะมาถึง** (ยังไม่ออก) · **ค้างจ่าย** · **ทั้งหมด** · **ยกเลิก**

### จองใหม่ / แก้ไข
- ปุ่ม **+ จองใหม่** ด้านล่าง หรือแตะช่อง + ในปฏิทิน
- **เลือกวันจากปฏิทิน** (ไม่ต้องพิมพ์): แตะช่องเช็คอิน → แตะวันเข้า → แตะวันออก ปฏิทินปิดเอง
  - วันสีแดง = ห้องที่เลือกไม่ว่างคืนนั้น · ส้ม = วันที่เลือก
  - แก้แค่วันออก: แตะช่องเช็คเอาท์แล้วแตะวันใหม่ · หรือกดปุ่ม **1 คืน / 2 คืน …**
- ใต้ช่องวันที่บอกทันที **"✓ ห้อง 3 ว่าง"** หรือ **"⚠ ห้อง 3 ถูกจองแล้ว…"** (ถ้าซ้อน ปุ่มบันทึกกดไม่ได้)
- **ต้องกรอก:** ห้อง วันที่ ชื่อผู้จอง เบอร์โทร (9–10 หลัก) จำนวนผู้ใหญ่ ยอดรวม
  (ปิดห้อง ไม่ต้องกรอกชื่อ/เบอร์/คน/ยอด)
- **ช่องที่ลืมกรอกหรือกรอกผิด ขึ้นสีแดง** พร้อมข้อความใต้ช่อง เมื่อกดบันทึก ระบบเลื่อนไปช่องแรกที่ผิดให้
  ช่องที่ผิดทันทีโดยไม่ต้องรอกดบันทึก: มัดจำมากกว่ายอดรวม · ชำระเกินยอดรวม
- ผู้บันทึก: วาฬ / แบม / เหมยๆ / อื่นๆ
- **ปิดห้อง** (ซ่อม/ไม่รับแขก): เลือกสถานะ "ปิดห้อง"

### เงิน (คำนวณให้อัตโนมัติ)
เลือกห้อง + วันที่ ระบบคำนวณจากราคาในชีตทันที

| รายการ | คิดจาก |
|---|---|
| ค่าห้อง | จำนวนคืน × "ราคา/คืน" ของห้อง (แท็บห้องพัก คอลัมน์ E) |
| เตียงเสริม | จำนวนเตียง × จำนวนคืน × "ราคาเตียงเสริม/คืน" (แท็บตั้งค่า) |
| หมูกระทะ | จำนวนชุด × "ราคาหมูกระทะ/ชุด" (แท็บตั้งค่า) → ใส่ในช่องค่าหมูกระทะ |
| **ยอดรวม** | ค่าห้อง + เตียงเสริม + หมูกระทะ |
| **มัดจำ** | ยอดรวม × "มัดจำ (%)" (ค่าเริ่มต้น 50%) ปัดขึ้น |
| **ชำระแล้ว** | ยอดที่ลูกค้าจ่ายมาแล้วทั้งหมด |
| **ค้างจ่าย** | ยอดรวม − ชำระแล้ว |

- **แก้ตัวเลขเองได้ทุกช่อง** (เช่น ลดราคา หรือมัดจำ 500) ช่องที่แก้เองแล้วจะไม่ถูกคำนวณทับ
  กดปุ่ม **"คำนวณใหม่ตามราคา"** เพื่อกลับไปใช้ค่าที่ระบบคำนวณ
- ถ้ายอดรวมต่างจากที่คำนวณ บิลจะแสดงบรรทัด **"ส่วนลด"** หรือ **"ปรับยอด"** ให้อัตโนมัติ
- สถานะเงิน "มัดจำแล้ว" ดูจากช่องมัดจำ (ถ้าว่างใช้ % ในแท็บตั้งค่า)
- การจองเดิมที่แก้ไข: ยอดที่บันทึกไว้แล้วไม่ถูกเปลี่ยน จนกว่าจะกดคำนวณใหม่

### รายละเอียดการจอง
ด้านบนมีกล่อง **ยอดรวม · มัดจำ · ชำระแล้ว · ค้างจ่าย**

| ปุ่ม | ทำอะไร |
|---|---|
| แก้ไข | เปิดฟอร์มแก้ทุกช่อง (เลื่อนวัน: แก้วันที่ แล้วจดวันเดิมในหมายเหตุ) |
| รับเงิน | ใส่จำนวนเงิน (ปุ่มลัด "มัดจำ" และ "ยอดที่เหลือ") + วิธีชำระ ระบบบวกเข้ายอดชำระแล้ว และจดในช่อง "การชำระ / หลักฐาน" เช่น `22/10/2026 รับ 1,000 บาท (โอน) · วาฬ` |
| ข้อความยืนยัน | สร้างข้อความแจ้งคอนเฟิม กด **คัดลอกข้อความ** แล้ววางในแชท LINE |
| บิล (รูปภาพ) | สร้างรูปบิลส่งให้ลูกค้า (ดูด้านล่าง) |
| ลูกค้าเข้าพักแล้ว | เปลี่ยนสถานะเมื่อลูกค้ามาถึง |
| ↩ ยกเลิกสถานะเข้าพัก | **กดผิดแก้กลับได้** เปลี่ยนจาก "เข้าพักแล้ว" กลับเป็น "จองแล้ว" |
| ยกเลิกการจอง | เปลี่ยนสถานะเป็น "ยกเลิก" (ไม่ลบข้อมูล) ห้องกลับเป็นว่างทันที |
| เปิดการจองคืน | (การจองที่ยกเลิก) เปิดคืนได้ถ้าห้องยังว่าง |

ไม่มีปุ่มลบ ตามกฎ "ห้ามลบแถว" ถ้าจำเป็นต้องลบจริง ให้ลบในชีต

### ข้อความยืนยัน (คัดลอกส่ง LINE)

```
✅ แจ้งคอนเฟิมที่พัก
🏡 ยูนนานโฮมสเตย์
━━━━━━━━━━━━━━
👤 คุณ ขวัญดาว พึ่งธรรม
📞 063-929-2669
🛏 ห้อง 4 · 4 ท่าน พร้อมอาหารเช้า
📅 เช็คอิน 01/01/2027 (หลัง 14:00 น.)
📅 เช็คเอาท์ 03/01/2027 (ก่อน 11:00 น.)
🌙 รวม 2 คืน
🔥 หมูกระทะ 1 ชุด · 300 บาท
━━━━━━━━━━━━━━
💰 ยอดรวม       3,300 บาท
💵 มัดจำ          500 บาท
✔️ ชำระแล้ว     500 บาท
⏳ ค้างชำระ      2,800 บาท
━━━━━━━━━━━━━━
✅ ได้รับมัดจำเรียบร้อย
ส่วนที่เหลือ 2,800 บาท ชำระวันเข้าพัก

ขอบคุณที่เลือกพักกับยูนนานโฮมสเตย์ 🙏
เลขที่จอง YN270101-01
```

- ติ๊ก **แบบแจ้งแก้ไข** เมื่อแก้การจองที่เคยยืนยันแล้ว บรรทัดแรกเป็น `⭐️ แก้ไข · แจ้งคอนเฟิมที่พัก ⭐️`
- บรรทัดท้ายเปลี่ยนตามสถานะเงิน
  - ยังไม่ถึงมัดจำ → "📌 กรุณาชำระมัดจำ … บาท" + เลขบัญชี (ถ้าใส่ "บัญชีรับเงิน" ในแท็บตั้งค่า)
  - มัดจำแล้ว → "✅ ได้รับมัดจำเรียบร้อย ส่วนที่เหลือ … ชำระวันเข้าพัก"
  - ครบ → "🎉 ชำระครบเรียบร้อยแล้ว"
- มีเด็ก → "4 ท่าน (ผู้ใหญ่ 2 เด็ก 2)" · มีเตียงเสริม → "➕ เสริมเตียง 1 เตียง" · หมายเหตุหมูกระทะต่อท้ายในวงเล็บ
- ข้อมูลไม่ครบ (เช่น การจองที่กรอกในชีตแล้วไม่ใส่เบอร์) จะขึ้น **"ยังขาด: …"** พร้อมปุ่มไปกรอก (ช่องที่ขาดเป็นสีแดง)
- วันที่ใช้ วว/ดด/ปปปป **ค.ศ.** ตามกฎของระบบ · แก้ถ้อยคำได้ที่ฟังก์ชัน `confirmText` ใน Admin.html

### บิล (รูปภาพ) สำหรับลูกค้า

กด **บิล (รูปภาพ)** ในหน้ารายละเอียด → ได้รูป PNG สวยๆ แบบใบเสร็จ หัวบิลสีเขียวแบบเดียวกับเว็บ

| สถานะเงิน | หัวบิล | ตราสถานะ | ข้อความท้ายบิล |
|---|---|---|---|
| ยังไม่จ่าย / ยังไม่ถึงมัดจำ | ใบแจ้งยอดการจอง | 🟡 รอชำระมัดจำ | กรุณาชำระมัดจำ … + เลขบัญชี |
| จ่ายมัดจำแล้ว (ค้างจ่าย) | ใบยืนยันการจอง | 🟠 ชำระมัดจำแล้ว | ชำระส่วนที่เหลือ … ในวันเข้าพัก |
| จ่ายครบ | ใบเสร็จรับเงิน | 🟢 ชำระครบแล้ว | ชำระครบเรียบร้อยแล้ว ขอบคุณ… |

ในบิลมี: เลขที่จอง วันที่ออกบิล ชื่อ เบอร์ ห้อง/จำนวนคน เช็คอิน–เช็คเอาท์ (พร้อมเวลา) รายการ (ค่าห้อง เตียงเสริม หมูกระทะ ส่วนลด)
ยอดรวม มัดจำ ชำระแล้ว ค้างชำระ เงื่อนไขมัดจำ และ LINE ติดต่อ

**ส่งให้ลูกค้า:** กด **แชร์ไป LINE** (มือถือที่รองรับ) หรือ **กดค้างที่รูป → บันทึกรูป/แชร์** หรือปุ่ม **บันทึกรูป**
ส่งบิลใหม่ได้ทุกครั้งที่สถานะเงินเปลี่ยน (เช่น ก่อนจ่าย → หลังจ่ายมัดจำ → จ่ายครบ)

### เมนู ⋮
เปิด Google Sheet · โหลดข้อมูลล่าสุด · เปลี่ยนผู้บันทึก · ออกจากระบบ

## ใช้คู่กับ Google Sheet

- ทีมงานกรอกในชีตได้ตามปกติ ([google-sheet.md](google-sheet.md)) หน้าหลังบ้านจะเห็นเมื่อกด **โหลดข้อมูลล่าสุด**
- แถวที่กรอกในชีตแต่ยังไม่มีเลขที่จอง ระบบจะเติมเลขที่จองให้ตอนเปิดหลังบ้าน
- ถ้ามีคนเรียงแถวในชีตใหม่ หลังบ้านหาแถวจาก **เลขที่จอง** จึงไม่แก้ผิดแถว
- สองคนบันทึกพร้อมกัน: ระบบให้บันทึกทีละคน (LockService) และตรวจห้องซ้อนกับข้อมูลล่าสุดในชีตทุกครั้ง
- หน้าหลังบ้าน **ไม่เขียนทับคอลัมน์สูตร** (คืน ค้างจ่าย สถานะเงิน) สูตรในชีตยังทำงานเหมือนเดิม

## ความปลอดภัย

- ลิงก์ `/exec` เปิดได้ทุกคน (เพราะต้องให้ลูกค้าเรียก API ห้องว่าง) แต่ **หน้าหลังบ้านต้องใส่รหัสทุกครั้ง** ข้อมูลการจองไม่ส่งออกไปถ้ารหัสผิด
- เปลี่ยนรหัสจาก 1234 ทันทีหลังติดตั้ง และเปลี่ยนใหม่เมื่อมีคนออกจากทีม (แก้ในแท็บตั้งค่า มีผลทันที ไม่ต้อง deploy)
- อย่าติ๊ก "จำรหัส" ในเครื่องที่คนอื่นใช้ด้วย

## ลองหน้าตาในเครื่อง (โหมดตัวอย่าง)

เปิดไฟล์ผ่านเซิร์ฟเวอร์ แล้วเข้า `apps-script/Admin.html` จะเป็นโหมดตัวอย่าง (ข้อมูลสมมติ รหัส `1234` ไม่บันทึกที่ไหน)

```bash
npx serve .
```

แล้วเปิด `http://localhost:3000/apps-script/Admin.html`

## สำหรับคนแก้โค้ด

- **ห้ามมีตัวอักษร `/*` หรือ `*/` ที่ไหนใน Admin.html** Apps Script จะตัดสิ่งที่ดูเหมือนคอมเมนต์ออก ทำให้โค้ดหายและหน้าค้าง คอมเมนต์ใช้ `//` เท่านั้น
- มี `<script>` ของเราได้ก้อนเดียว
- ฟังก์ชันฝั่งเซิร์ฟเวอร์ที่หน้าเว็บเรียก: `adminData`, `saveBooking`, `addPayment`, `setBookingStatus` (ทุกตัวเรียก `auth_(pin)` ก่อน)
  ถ้าเพิ่มฟังก์ชันใหม่ ต้องเพิ่มใน `mock()` ของ Admin.html ด้วย (เทสต์ตรวจ)
- `payStatus` / `findConflict` ใน Admin.html ต้องตรงกับ `payStatus_` / `findConflict_` ใน Code.gs (เทสต์ตรวจ payStatus)
- เทสต์: `node tests/admin.test.js`
