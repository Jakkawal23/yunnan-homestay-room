# หน้าเว็บ (หน้าดูห้องพัก + หน้าเช็คห้องว่าง)

เว็บเป็นไฟล์ HTML ธรรมดา ไม่ต้อง build ไม่ต้องติดตั้งอะไร อัปโหลดขึ้น GitHub Pages หรือ Vercel ได้เลย
**ข้อมูลและลิงก์ทั้งหมดแก้ที่ไฟล์เดียว: [`assets/config.js`](../assets/config.js)**

## ไฟล์

| ไฟล์ | คืออะไร | ต้องแก้บ่อยไหม |
|---|---|---|
| `index.html` | หน้าดูห้องพัก | แทบไม่ต้องแก้ |
| `check.html` | หน้าเช็คห้องว่าง | แทบไม่ต้องแก้ |
| `assets/config.js` | **ตั้งค่าทั้งหมด** ลิงก์ ห้อง ราคา ข้อความ LINE | ✏️ แก้ที่นี่ |
| `assets/common.js` | ฟังก์ชันที่ 2 หน้าใช้ร่วม (สร้างลิงก์ LINE วันที่ รูป ไอคอน) | ไม่ต้องแก้ |
| `assets/common.css` | สี ฟอนต์ ปุ่ม แถบเมนูที่ 2 หน้าใช้ร่วม | แก้เมื่ออยากเปลี่ยนสีทั้งเว็บ |
| `images/` | รูปทั้งหมด | เพิ่ม/เปลี่ยนรูป |

## หน้าดูห้องพัก (`index.html`)

ส่วนต่างๆ จากบนลงล่าง: รูปหน้าที่พัก · จุดเด่น 4 ข้อ · การ์ดห้อง · บรรยากาศ · รายละเอียดการเข้าพัก · ขั้นตอนจอง · แผนที่ · ติดต่อ

| ปุ่ม | ไปที่ |
|---|---|
| "เช็คห้องว่าง" (เมนูบน, หน้าแรก, แถบล่าง, ส่วนติดต่อ) | `check.html` |
| "เช็ควันว่าง" บนการ์ดห้อง | `check.html?room=R3` (เลือกห้องนั้นไว้ให้) |
| "รายละเอียด" หรือกดรูป | เปิดหน้าต่างรูปและรายละเอียดห้อง |
| ในหน้าต่างห้อง: "ทัก LINE สอบถามห้องนี้" | แชท LINE + ข้อความ `room` |
| "LINE" / "แชท LINE" | แชท LINE + ข้อความ `general` |

**ลิงก์พิเศษ**
- `index.html#R3` → เปิดหน้าต่างห้อง 3 ทันที
- `index.html?from=check&in=2026-12-25&out=2026-12-27#R3` → (หน้าเช็คห้องว่างส่งมาแบบนี้)
  - ด้านบนมีแถบ **"← กลับไปหน้าเช็คห้องว่าง"**
  - ในหน้าต่างห้อง ปุ่มเปลี่ยนเป็น **"สนใจจองห้องนี้ (2 คืน)"** (ส่งวันที่ไปใน LINE ด้วย) และ **"กลับไปเช็ควันว่าง"**

## หน้าเช็คห้องว่าง (`check.html`)

1. โหลดข้อมูลห้องว่างจาก API (`urls.availabilityApi`)
2. แถบเลือกห้อง: **ทุกห้อง / ห้อง 1 … ห้อง 5**
3. ปฏิทิน (เลื่อนเดือนด้วยปุ่ม ‹ › หรือปัดซ้าย-ขวา เลือกล่วงหน้าได้ 365 วัน)
   - ทุกห้อง: แต่ละวันบอก `ว่าง 3` หรือ `เต็ม` · เลือก 1 ห้อง: บอก `ว่าง` / `เต็ม`
   - สี: เขียว = ว่าง · เหลือง = เหลือ 1 ห้อง · แดง = เต็ม · ส้ม = วันที่เลือก
   - "ว่าง" หมายถึง **คืน** ของวันนั้นว่าง
4. แตะวันเข้า → แตะวันออก → แสดงรายการห้อง (ห้องว่างขึ้นก่อน)
   - ห้องว่าง: ปุ่ม **ดูห้อง** และ **สนใจจอง** (เปิด LINE + ข้อความ `booking`)
   - ห้องไม่ว่าง: บอกคืนที่เต็ม เช่น "เต็มคืน 25/12/2026" มีแค่ปุ่มดูห้อง
5. แถบล่าง: วันที่เลือก · ปุ่ม "ล้าง" · ปุ่ม "ทัก LINE"

**ลิงก์พิเศษ** (ใช้ส่งให้ลูกค้าในแชทได้)
- `check.html?room=R3` → เลือกห้อง 3 ไว้ให้
- `check.html?in=2026-12-25&out=2026-12-27` → เลือกวันไว้ให้ (ภายในลิงก์ใช้ ปปปป-ดด-วว)
- ลิงก์ในแถบที่อยู่จะเปลี่ยนตามที่ลูกค้าเลือก กดย้อนกลับมาแล้วยังเป็นค่าเดิม

**เมื่อยังไม่ได้เชื่อม API** (`availabilityApi: ''`) จะขึ้นกล่องสีเหลือง "โหมดตัวอย่าง" และใช้ข้อมูลสมมติ ไว้ดูหน้าตา
**เมื่อโหลดไม่สำเร็จ** จะขึ้นกล่องสีแดงพร้อมปุ่ม "ลองใหม่" และ "ทัก LINE"

### `lineMessages` ข้อความที่พิมพ์ให้ในแชท

|---|---|

### `rooms` ห้องพัก
```js
{ id:'R3', name:'ห้อง 3', bed:'เตียงคู่', capacity:4, extra:2, from:1500, tag:'ห้องใหญ่',
  desc:'คำอธิบาย', features:['รวมอาหารเช้า','เสริมเตียงได้ 2 ท่าน'],
  folder:'room_03', photos:['01','02','03','04','05'] }
```
| ช่อง | ความหมาย |
|---|---|
| `id` | **ต้องตรงกับรหัสห้องในแท็บห้องพักของ Google Sheet** ไม่งั้นหน้าเช็คห้องว่างจะถือว่าห้องนี้ "งดให้บริการ" |
| `from` | ราคาเริ่มต้นต่อคืน (พิมพ์เอง ไม่ได้ดึงจากชีต) |
| `extra` | จำนวนเตียงเสริมที่เสริมได้ |
| `tag` | ป้ายมุมรูป (ไม่ใส่ก็ได้) |
| `folder` + `photos` | รูปอยู่ที่ `images/<folder>/<ชื่อ>.jpg` และรูปเล็ก `images/<folder>/small/<ชื่อ>.jpg` รูปแรก = หน้าปก |

### อื่นๆ
- `spaces` การ์ดพื้นที่ส่วนกลาง (รูปที่ `images/<photo>.jpg` และ `images/small/<photo>.jpg`)
- `highlights` ภาพบรรยากาศ `[รหัสห้อง, ชื่อรูป, คำบรรยาย]` กดแล้วเปิดห้องนั้นที่รูปนั้น
- `facts` จุดเด่น 4 ข้อ (`icon`: cup, pin, fire, bed, user, clock, wallet, info, plus, nav, moon, table, cal, chat, image)
- `houseRules` ข้อควรทราบ

## เพิ่ม/เปลี่ยนรูป

- รูปห้องใหญ่กว้าง **1600px** รูปเล็ก **640px** ไฟล์ `.jpg`
- ไฟล์ต้นฉบับใหญ่ๆ เก็บใน `originals/` (ไม่ขึ้น GitHub)
- ย่อรูปด้วย ffmpeg (มีในเครื่องแล้ว):

```bash
ffmpeg -i originals/room_01/06.png -vf scale=1600:-2 -q:v 4 images/room_01/06.jpg
```

```bash
ffmpeg -i originals/room_01/06.png -vf scale=640:-2 -q:v 5 images/room_01/small/06.jpg
```

แล้วเพิ่ม `'06'` ใน `photos` ของห้องนั้น

## เปลี่ยนราคา

แก้ `from` ใน `rooms` ของ `config.js` (ราคานี้แสดงบนเว็บเท่านั้น ราคาจริงแอดมินแจ้งในแชท)

## ดูเว็บในเครื่องก่อนอัปโหลด

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (ดับเบิลคลิกเปิดไฟล์ตรงๆ รูปและ config.js จะโหลดไม่ขึ้นในบางเบราว์เซอร์)

```bash
npx serve .
```

แล้วเปิด `http://localhost:3000` และ `http://localhost:3000/check.html`

**ตรวจทุกครั้งหลังแก้:** เปิดทั้ง 2 หน้าที่ความกว้างมือถือ (375px) ต้องไม่มีแถบเลื่อนซ้าย-ขวา และกดปุ่มไปมาระหว่าง 2 หน้าได้
