# ภาพรวมระบบ

ระบบนี้มี 3 ส่วน ทำงานร่วมกันแบบนี้

```
                       LINE OA (Rich menu)
                ┌──────────────┴──────────────┐
                ▼                             ▼
     ┌────────────────────┐         ┌────────────────────┐
     │  หน้าดูห้องพัก        │ ◄─────► │  หน้าเช็คห้องว่าง      │
     │  index.html         │  ลิงก์   │  check.html         │
     └─────────┬──────────┘  ไปมา   └─────────┬──────────┘
               │                              │ อ่านห้องว่าง (JSON)
               │ กด "สนใจจอง"                   ▼
               │                    ┌────────────────────┐
               └──────► แชท LINE ◄── │  Apps Script (API)  │
                  พิมพ์ข้อความให้       │  Code.gs            │
                  อัตโนมัติ             └─────────┬──────────┘
                                              │ อ่านอย่างเดียว
                                              ▼
                                   ┌────────────────────┐   อ่าน/เขียน  ┌──────────────────────┐
                                   │  Google Sheet       │ ◄──────────► │  หลังบ้าน (Admin.html)  │
                                   │  ปฏิทินห้องพัก        │              │  .../exec?page=admin  │
                                   └────────────────────┘              └──────────────────────┘
                                     ▲ ทีมงานกรอกตรงในชีตก็ได้              ▲ ทีมงานใช้ในมือถือ (มีรหัส)
```

| ส่วน | ไฟล์ | อยู่ที่ไหน | ใครใช้ |
|---|---|---|---|
| หน้าดูห้องพัก | `index.html` | GitHub Pages หรือ Vercel | ลูกค้า: ดูรูป รายละเอียด ราคาเริ่มต้น |
| หน้าเช็คห้องว่าง | `check.html` | ที่เดียวกับหน้าดูห้องพัก | ลูกค้า: เลือกวัน ดูห้องว่าง กดจองผ่าน LINE |
| ตั้งค่าเว็บ | `assets/config.js` | ที่เดียวกัน | ทีมงาน: แก้ลิงก์ ราคา ข้อความ LINE |
| Google Sheet ปฏิทินห้องพัก | (สร้างใน Google Drive) | Google Drive | ทีมงาน: บันทึกการจองและเงิน |
| API ห้องว่าง | `apps-script/Code.gs` | Apps Script ที่ผูกกับชีต | หน้าเช็คห้องว่างเรียกใช้ |
| หลังบ้าน | `apps-script/Admin.html` + `Code.gs` | Apps Script (ลิงก์เดียวกัน + `?page=admin`) | ทีมงาน: ดู เพิ่ม แก้ไข รับเงิน ผ่านมือถือ |

## ลูกค้าใช้งานอย่างไร

1. กด Rich menu ใน LINE OA
   - **"ดูห้องพัก"** → เปิดหน้าดูห้องพัก
   - **"เช็คห้องว่าง"** → เปิดหน้าเช็คห้องว่าง
2. หน้าเช็คห้องว่าง: แตะวันเข้าพักและวันออกในปฏิทิน ระบบแสดงทันทีว่าห้องไหนว่าง
3. กด **"ดูห้อง"** → ไปหน้าดูห้องพักที่เปิดรูปห้องนั้นให้เลย มีปุ่ม **"กลับไปเช็ควันว่าง"** (วันที่ที่เลือกไว้ยังอยู่)
4. กด **"สนใจจอง"** → เปิดแชท LINE OA และพิมพ์ข้อความให้อัตโนมัติ เช่น

   ```
   สวัสดี สนใจจองห้องพัก ยูนนานโฮมสเตย์
   🏠 ห้อง 3 (เตียงคู่ · 4 ท่าน)
   📅 เช็คอิน 25/12/2026
   📅 เช็คเอาท์ 27/12/2026 (2 คืน)
   👥 จำนวนผู้เข้าพัก:  ท่าน
   รบกวนแอดมินยืนยันห้องว่างด้วย
   ```

   ลูกค้าเติมจำนวนคน แล้วกดส่งเอง (ระบบไม่ได้ส่งแทน)
5. แอดมินตอบในแชท ยืนยันห้อง แจ้งราคาและมัดจำ แล้วบันทึกลง Google Sheet

## ทีมงานใช้งานอย่างไร

เลือกได้ 2 ทาง ข้อมูลที่เดียวกัน
- **หน้าหลังบ้าน** (แนะนำในมือถือ) `.../exec?page=admin` ใส่รหัส → ปฏิทิน รายการจอง จองใหม่ แก้ไข รับเงิน ยกเลิก (ดู [admin.md](admin.md))
- **Google Sheet โดยตรง** แท็บ **"การจอง"** กรอก 1 แถวต่อ 1 ห้อง แท็บ **"ปฏิทิน"** ดูภาพรวม (ดู [google-sheet.md](google-sheet.md))

หน้าเช็คห้องว่างของลูกค้าอัปเดตเองภายใน 1 นาที ไม่ต้องทำอะไรเพิ่ม

**ทำไมหลังบ้านอยู่บน Apps Script แต่หน้าลูกค้าไม่อยู่:** หลังบ้านต้องอ่าน/เขียนชีตได้โดยตรง และคนใช้มีแค่ทีมงาน
แถบเตือนของ Google ด้านบนจึงไม่เป็นปัญหา ส่วนหน้าลูกค้าอยู่บน GitHub/Vercel เพื่อหน้าตาสะอาดและโหลดเร็ว

## ทำไมออกแบบแบบนี้

**หน้าเช็คห้องว่างอยู่บน GitHub Pages/Vercel ไม่ได้อยู่บน Apps Script โดยตรง**
Apps Script ทำหน้าที่เป็น "API" ส่งข้อมูลห้องว่างอย่างเดียว เหตุผล:

- หน้าเว็บที่ Apps Script สร้างจะมีแถบเตือนของ Google ด้านบน ("This application was created by a Google Apps Script user") ลูกค้าอาจตกใจ
- ทั้ง 2 หน้าอยู่เว็บเดียวกัน ลิงก์ไปมาง่าย ไม่ต้องห่วงเรื่อง iframe ของ Apps Script
- หน้าตา สี ฟอนต์ ใช้ไฟล์เดียวกัน (`assets/common.css`)
- โหลดเร็วกว่า และถ้า API ล่ม หน้ายังเปิดได้และมีปุ่มทัก LINE ให้
- ย้ายที่ deploy ได้ง่าย แก้แค่ `assets/config.js`

**API ไม่ส่งข้อมูลส่วนตัว** ส่งแค่ "ห้องไหนไม่ว่างช่วงวันที่ไหน" ชื่อ เบอร์ ยอดเงิน ไม่หลุดออกไปแน่นอน (มีเทสต์ตรวจ)

**กดจองแล้วไป LINE ไม่ใช่ฟอร์มจอง** ตามที่ตกลงกันไว้ว่าลูกค้ายังใช้ระบบจองออนไลน์ไม่คล่อง
ลิงก์ที่ใช้คือ `https://line.me/R/oaMessage/@579lmqrb/?ข้อความ` ซึ่ง LINE รองรับการพิมพ์ข้อความให้ล่วงหน้า
(ลิงก์ `lin.ee/...` แบบเดิมทำแบบนี้ไม่ได้)

## ระบบจองออนไลน์เดิม (พักไว้ก่อน)

ระบบจองเต็มรูปแบบที่ทำไว้ก่อนหน้า (หน้าจอง + หลังบ้าน + ชีต 6 แท็บ) **ไม่ได้ถูกลบหรือแก้ไข**
แค่หน้าเว็บนี้ไม่ลิงก์ไปที่นั่นแล้ว ถ้าจะกลับไปใช้ในอนาคต ดูหัวข้อ "ถ้าจะกลับไปใช้ระบบจองเดิม" ใน [deploy-and-urls.md](deploy-and-urls.md)
