# Apps Script (API ห้องว่าง)

ไฟล์ใน Apps Script มี 2 ไฟล์
- [`apps-script/Code.gs`](../apps-script/Code.gs) → ไฟล์ชื่อ **Code.gs**
- [`apps-script/Admin.html`](../apps-script/Admin.html) → ไฟล์ HTML ชื่อ **Admin** (กด + → HTML → พิมพ์ `Admin`)
- ([`appsscript.json`](../apps-script/appsscript.json) ไม่บังคับ)

สคริปต์นี้ "ผูก" กับ Google Sheet ปฏิทินห้องพัก มีหน้าที่ 3 อย่าง
1. **สร้างและดูแลชีต:** สร้างแท็บ สูตร สี dropdown เติมเลขที่จอง (`setup`, `onOpen`, `onEdit`)
2. **เป็น API:** เมื่อหน้าเช็คห้องว่างเรียกลิงก์ `/exec` จะส่งข้อมูลห้องว่างกลับไป (`doGet`)
3. **หน้าหลังบ้าน:** ลิงก์ `/exec?page=admin` เปิดเว็บสำหรับทีมงาน ดู เพิ่ม แก้ไขการจอง (ดู [admin.md](admin.md))

**ลิงก์เดียว ใช้ 2 แบบ**

| ลิงก์ | ได้อะไร | ใครใช้ |
|---|---|---|
| `.../exec` | JSON ห้องว่าง (ไม่มีข้อมูลส่วนตัว) | หน้าเช็คห้องว่างของลูกค้า |
| `.../exec?page=admin` | หน้าเว็บหลังบ้าน (ต้องใส่รหัส) | ทีมงาน |

## ติดตั้งครั้งแรก

1. ทำตามหัวข้อ "สร้างชีต" ใน [google-sheet.md](google-sheet.md) ให้เสร็จก่อน (วางโค้ดและรัน `setup`)
   และเพิ่มไฟล์ HTML ชื่อ **Admin** วางเนื้อหาจาก `apps-script/Admin.html` (ถ้าไม่มีไฟล์นี้ API ยังใช้ได้ แต่หน้าหลังบ้านจะเปิดไม่ได้)
2. ใน Apps Script กด **Deploy → New deployment**
3. กดรูปฟันเฟือง ⚙ ข้าง "Select type" → เลือก **Web app**
4. ตั้งค่า
   - Description: `API ห้องว่าง`
   - Execute as: **Me** (บัญชีเจ้าของชีต)
   - Who has access: **Anyone**
5. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
6. เปิดลิงก์นั้นในเบราว์เซอร์ ต้องเห็นข้อความแบบนี้ = ใช้ได้

   ```json
   {"ok":true,"today":"2026-10-21","updatedAt":"21/10/2026 10:00","rooms":[...],"closed":[],"busy":{"R1":[],...}}
   ```
7. เอาลิงก์ไปใส่ใน `assets/config.js`

   ```js
   urls: {
     ...
     availabilityApi: 'https://script.google.com/macros/s/AKfy....../exec'
   },
   ```
8. อัปโหลดขึ้น GitHub (ดู [deploy-and-urls.md](deploy-and-urls.md)) หน้าเช็คห้องว่างจะเลิกแสดง "โหมดตัวอย่าง"

> "Who has access: Anyone" แปลว่าใครก็เปิดลิงก์ `/exec` ได้ แต่ข้อมูลที่ได้มีแค่ "ห้องไหนไม่ว่างวันไหน"
> ไม่มีชื่อ เบอร์ หรือยอดเงิน ส่วนตัวชีตยังเปิดได้เฉพาะคนที่แชร์ให้

## แก้โค้ดแล้วต้องทำอะไร

1. วางโค้ดใหม่ทับใน Apps Script แล้วบันทึก
2. ถ้าการแก้เกี่ยวกับชีต (คอลัมน์ สูตร สี) ให้รัน `setup` อีกครั้ง
3. **Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy**

> ต้องเลือก **Manage deployments → New version** เท่านั้น
> ถ้ากด **New deployment** จะได้ลิงก์ `/exec` ใหม่ ต้องไปเปลี่ยนใน config.js อีก

## API ส่งอะไรกลับไป

`GET https://script.google.com/macros/s/.../exec`

```json
{
  "ok": true,
  "today": "2026-10-21",
  "updatedAt": "21/10/2026 10:00",
  "rooms": [{ "id": "R1", "name": "ห้อง 1" }, { "id": "R2", "name": "ห้อง 2" }],
  "closed": ["R5"],
  "busy": {
    "R1": [["2026-10-25", "2026-10-27"]],
    "R2": []
  }
}
```

| ช่อง | ความหมาย |
|---|---|
| `today` | วันนี้ (เวลาไทย) |
| `updatedAt` | เวลาที่อ่านชีตล่าสุด (แสดงท้ายหน้าเช็คห้องว่าง) |
| `rooms` | ห้องทั้งหมดในแท็บห้องพัก |
| `closed` | ห้องที่ตั้ง "เปิดให้จอง = ไม่" |
| `busy` | ช่วงที่ไม่ว่างของแต่ละห้อง `[วันเข้า, วันออก]` วันออกไม่นับ (คืนนั้นว่าง) |

**การจองที่นับว่าไม่ว่าง:** ทุกแถวที่มีห้อง + วันเข้า + วันออก ยกเว้นสถานะ `ยกเลิก`
(รวม "ปิดห้อง" และ "เข้าพักแล้ว") ส่งเฉพาะช่วงที่ยังไม่จบ และไม่เกิน 400 วันข้างหน้า ช่วงที่ต่อกันจะรวมเป็นช่วงเดียว

**ถ้ามีข้อผิดพลาด** จะได้ `{"ok":false,"error":"..."}` หน้าเว็บจะแสดง "โหลดข้อมูลห้องว่างไม่สำเร็จ" พร้อมปุ่มทัก LINE

**JSONP:** ถ้าต่อท้าย `?callback=ชื่อฟังก์ชัน` จะได้ `ชื่อฟังก์ชัน({...})` ใช้สำรองเมื่อเบราว์เซอร์เรียกแบบปกติไม่ได้ (หน้าเว็บสลับให้เอง)

## ความเร็วและแคช

- ผลลัพธ์ถูกเก็บแคชไว้ **60 วินาที** ลูกค้าหลายคนเปิดพร้อมกันก็ไม่ช้า
- ทุกครั้งที่ทีมงานแก้ชีต (`onEdit`) แคชจะถูกล้าง ลูกค้าเห็นข้อมูลใหม่ทันทีในการโหลดครั้งต่อไป
- ถ้าแก้ชีตจากแอปมือถือแล้วบางครั้งแคชไม่ถูกล้าง ข้อมูลจะอัปเดตเองภายใน 1 นาที

## ฟังก์ชันใน Code.gs

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `setup()` | สร้าง/ซ่อมทุกแท็บ ตั้งภาษาชีตเป็น en_GB (วันที่ วว/ดด/ปปปป) และเขตเวลาไทย รันซ้ำได้ ข้อมูลไม่หาย |
| `onOpen()` | สร้างเมนู 🏠 โฮมสเตย์ และตั้งปฏิทินเป็นเดือนปัจจุบัน (ทำงานเองตอนเปิดชีต) |
| `goToThisMonth()` | ตั้งปฏิทินเป็นเดือนนี้ |
| `onEdit(e)` | เมื่อแก้แท็บการจอง: เติมเลขที่จอง `YNyyMMdd-NN` และเวลาบันทึก แล้วล้างแคช (ทำงานเอง) |
| `doGet(e)` | API ห้องว่าง · ถ้ามี `?page=admin` แสดงหน้าหลังบ้าน |
| `showAdminLink()` | เมนู 🏠 → เปิดหลังบ้าน (เว็บ): แสดงลิงก์หลังบ้าน |
| `adminData(pin)` | หลังบ้าน: ตรวจรหัส โหลดการจองทั้งหมด (เติมเลขที่จองให้แถวที่ยังไม่มี) |
| `saveBooking(pin, b)` | หลังบ้าน: เพิ่ม/แก้การจอง ตรวจข้อมูลและห้องซ้อนก่อนบันทึก ไม่เขียนทับคอลัมน์สูตร |
| `addPayment(pin, p)` | หลังบ้าน: บวกยอดชำระแล้ว + จดประวัติในช่องการชำระ |
| `setBookingStatus(pin, id, row, status)` | หลังบ้าน: เปลี่ยนสถานะ (ยกเลิก / เข้าพักแล้ว / เปิดคืน) |
| `buildAvailability_()` | แปลงแถวในชีตเป็นช่วงวันที่ไม่ว่าง (ไม่มีข้อมูลส่วนตัว) |
| `buildCalendar_()` | สร้างแท็บปฏิทินทั้งหมดด้วยสูตร |

ค่าที่ปรับได้ด้านบนไฟล์: `CACHE_SECONDS` (60), `API_DAYS_AHEAD` (400), `BOOKING_ROWS` (1000 แถว), `SEED_LISTS` (ตัวเลือกเริ่มต้น), `COLOR` (สี)

**ลำดับคอลัมน์ `COLS`** โค้ดอ่านข้อมูลตามตำแหน่งคอลัมน์ ห้ามสลับ ถ้าจะเพิ่มคอลัมน์ ให้เพิ่มท้ายรายการ แล้วรัน `setup`

## ทดสอบ

```bash
node tests/code.test.js
```

```bash
node tests/admin.test.js
```

ทดสอบตรรกะการคำนวณห้องว่าง วันที่ เลขที่จอง API (รวมถึงตรวจว่าชื่อ/เบอร์/ยอดเงินไม่หลุดออกไป)
และฟังก์ชันหลังบ้านกับชีตจำลอง (รหัส บันทึก กันจองซ้อน รับเงิน ยกเลิก ไม่เขียนทับคอลัมน์สูตร)
ส่วนสร้างชีต (`setup`, สูตรปฏิทิน, สี) ทดสอบในเครื่องไม่ได้ ต้องลองใน Google Sheet จริง

## ปัญหาที่อาจเจอ

| อาการ | วิธีแก้ |
|---|---|
| เปิด `/exec` แล้วขึ้นหน้าให้ล็อกอิน Google | ตอน Deploy ไม่ได้ตั้ง Who has access = **Anyone** → Manage deployments → ✏️ → แก้ → New version |
| เปิด `/exec` แล้วได้ `"ok":false` | อ่านข้อความ error ส่วนใหญ่คือยังไม่ได้รัน `setup` หรือเปลี่ยนชื่อแท็บ (ห้ามเปลี่ยนชื่อแท็บ) |
| แก้โค้ดแล้วเว็บยังเหมือนเดิม | ลืม Deploy เป็น New version |
| หน้าเว็บขึ้น "โหมดตัวอย่าง" | ยังไม่ได้ใส่ `availabilityApi` ใน config.js หรือยังไม่ได้อัปโหลดไฟล์ config.js ใหม่ขึ้นเว็บ |
| เปิด `?page=admin` แล้วขึ้น "No HTML file named Admin" | ยังไม่ได้เพิ่มไฟล์ HTML ชื่อ `Admin` (ต้องสะกดตรง ตัว A ใหญ่) |
| หลังบ้านค้างที่หน้าว่าง / กดอะไรไม่ได้ | วาง Admin.html ไม่ครบ หรือมีคนแก้แล้วมี `/*` ในไฟล์ ให้วางใหม่ทั้งไฟล์ |
| หลังบ้านขึ้น "ยังไม่ได้ตั้ง รหัสเข้าหลังบ้าน" | รัน `setup` อีกครั้ง หรือเพิ่มแถว `รหัสเข้าหลังบ้าน` ในแท็บตั้งค่าเอง |
