# Google Sheet ปฏิทินห้องพัก

ชีตนี้คือ "สมุดจอง" ของโฮมสเตย์ ทีมงานกรอกการจองที่นี่ และหน้าเช็คห้องว่างของลูกค้าอ่านจากที่นี่
จะกรอกในชีตโดยตรง หรือผ่าน **หน้าหลังบ้าน** ในมือถือ ([admin.md](admin.md)) ก็ได้ ข้อมูลที่เดียวกัน

> ชีตนี้เป็น **ชีตใหม่** แยกจากชีตของระบบจองเดิม ไม่ต้องไปแก้ชีตเก่า

## สร้างชีต (ทำครั้งเดียว)

1. เข้า [sheets.new](https://sheets.new) สร้าง Google Sheet ว่าง ตั้งชื่อเช่น `ปฏิทินห้องพัก ยูนนานโฮมสเตย์`
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดทั้งหมดจาก [`apps-script/Code.gs`](../apps-script/Code.gs)
4. กดบันทึก (ไอคอนแผ่นดิสก์) เลือกฟังก์ชัน `setup` ด้านบน แล้วกด **Run**
5. ครั้งแรก Google จะขอสิทธิ์ กด **Review permissions** → เลือกบัญชี → **Advanced** → **Go to ... (unsafe)** → **Allow**
   (ขึ้น "unsafe" เพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ได้ผ่านการตรวจของ Google ปลอดภัย)
6. กลับไปที่ชีต จะเห็น 5 แท็บ: **ปฏิทิน · การจอง · ห้องพัก · ตั้งค่า · วิธีใช้** และเมนู **🏠 โฮมสเตย์** ด้านบน

7. (สำหรับหน้าหลังบ้าน) ใน Apps Script กด **+ → HTML** ตั้งชื่อ `Admin` แล้ววางเนื้อหาจาก [`apps-script/Admin.html`](../apps-script/Admin.html)
8. ในแท็บ **ตั้งค่า** เปลี่ยน **รหัสเข้าหลังบ้าน** จาก `1234` เป็นรหัสของทีม

ขั้นต่อไป: Deploy เป็น Web app ดู [apps-script.md](apps-script.md) แล้วใช้หลังบ้านตาม [admin.md](admin.md)

**แชร์ชีตให้ทีมงาน:** กด Share แล้วใส่อีเมลของวาฬ แบม เหมยๆ เป็น **Editor**
อย่าตั้งเป็น "Anyone with the link" เพราะในชีตมีชื่อและเบอร์ลูกค้า

## แท็บต่างๆ

### 1. ปฏิทิน (ดูอย่างเดียว)

หน้าตาแบบปฏิทินแขวนผนัง 1 เดือน (อาทิตย์–เสาร์) แต่ละวันมี 5 บรรทัด = ห้อง 1–5

| ในช่องเขียนว่า | ความหมาย | สี |
|---|---|---|
| `ว่าง` | ห้องว่างคืนนั้น | เขียว |
| `สมชาย · รอมัดจำ` | มีคนจอง ยังไม่จ่าย | เหลือง |
| `สมชาย · มัดจำแล้ว` | จ่ายมัดจำแล้ว | ส้ม |
| `สมชาย · ชำระครบ` | จ่ายครบแล้ว | ฟ้า |
| `⛔ ปิดห้อง` | ปิดซ่อม/ไม่รับแขก | เทา |
| `⚠ จองซ้อน: ...` | มี 2 การจองชนกัน ต้องแก้ทันที | แดง |
| `▶ สมชาย · ...` | ▶ = วันที่ลูกค้าคนนี้เช็คอิน | |

- **เปลี่ยนเดือน:** เลือกเดือนในช่องสีเหลือง (B2) และพิมพ์ปีในช่อง E2
- เปิดชีตทุกครั้ง ระบบจะตั้งเป็น **เดือนปัจจุบัน** ให้เอง หรือกดเมนู **🏠 โฮมสเตย์ → ไปที่เดือนนี้**
- วันนี้เป็นพื้นสีส้ม วันที่ไม่ใช่เดือนนี้เป็นสีจาง
- **ห้ามพิมพ์ในช่องวัน** ทุกช่องเป็นสูตรที่ดึงจากแท็บการจอง (ถ้าพิมพ์ จะมีคำเตือนขึ้น)

### 2. การจอง (กรอกที่นี่)

**1 แถว = 1 ห้อง** ถ้าลูกค้าจอง 2 ห้อง ให้กรอก 2 แถว ชื่อเดียวกัน (ใส่ยอดเงินแยกตามห้อง หรือใส่รวมไว้แถวแรกก็ได้)

| คอลัมน์ | ต้องกรอก | วิธีกรอก |
|---|---|---|
| A เลขที่จอง | — | **ระบบเติมให้** เช่น `YN261021-01` เมื่อเลือกห้อง |
| B ห้อง | ✅ | เลือกจาก dropdown |
| C เช็คอิน | ✅ | พิมพ์ `25/12/2026` หรือดับเบิลคลิกเลือกจากปฏิทิน |
| D เช็คเอาท์ | ✅ | วันที่ลูกค้า **ออก** (คืนสุดท้ายคือคืนก่อนหน้า) |
| E คืน | — | ระบบคำนวณ |
| F ชื่อผู้จอง | ✅ | |
| G เบอร์โทร | | พิมพ์ได้เลย เลข 0 ข้างหน้าไม่หาย |
| H ชื่อ LINE / Facebook | | ชื่อที่ลูกค้าใช้ทักมา |
| I ช่องทาง | | LINE / Facebook / โทรศัพท์ / Walk-in / Agoda / Booking.com / อื่นๆ |
| J ผู้ใหญ่ · K เด็ก · L เตียงเสริม · M หมูกระทะ (ชุด) | | ตัวเลข |
| N ยอดรวม (บาท) | | ยอดทั้งหมดที่ลูกค้าต้องจ่าย **รวมค่าหมูกระทะแล้ว** |
| O ชำระแล้ว (บาท) | | ยอดที่ลูกค้าจ่ายมาแล้ว **รวมทั้งหมด** (มัดจำ + ส่วนที่เหลือ) |
| P ค้างจ่าย | — | ระบบคำนวณ = ยอดรวม − ชำระแล้ว |
| Q สถานะเงิน | — | ระบบคำนวณ (ดูด้านล่าง) |
| R สถานะการจอง | | เว้นว่าง = จองแล้ว · `เข้าพักแล้ว` · `ยกเลิก` · `ปิดห้อง` |
| S การชำระ / หลักฐาน | | เช่น `มัดจำ 750 โอน KBank 20/10/2026, ที่เหลือจ่ายสด` |
| T ผู้บันทึก | | วาฬ / แบม / เหมยๆ / อื่นๆ |
| U หมายเหตุ | | เช่น มาถึงประมาณ 2 ทุ่ม, แพ้อาหารทะเล |
| V บันทึกเมื่อ | — | **ระบบเติมให้** |
| W ค่าหมูกระทะ (บาท) | | ราคาหมูกระทะรวม เช่น 1 ชุด 300 (ใช้ในข้อความยืนยัน) |
| X หมายเหตุหมูกระทะ | | เช่น ทานตอน 1 ทุ่ม, ไม่ทานเนื้อ |
| Y มัดจำ (บาท) | | ยอดมัดจำที่ต้องจ่าย (หลังบ้านใส่ให้ 50% อัตโนมัติ) เว้นว่าง = คิดจาก % ในแท็บตั้งค่า |

ช่องพื้นสีเทา (A, E, P, Q, V) ระบบเติมหรือคำนวณให้ ไม่ต้องกรอก
ถ้าจะใช้ปุ่ม "ข้อความยืนยัน" ในหลังบ้าน ต้องมี ชื่อ เบอร์โทร ผู้ใหญ่ ยอดรวม (และค่าหมูกระทะถ้าสั่งหมูกระทะ)
ชีตที่ติดตั้งไว้ก่อน: รัน **setup** อีกครั้ง ระบบจะเพิ่มคอลัมน์ W–Y ราคาห้อง (แท็บห้องพัก คอลัมน์ E) ราคาเตียงเสริม/หมูกระทะ บัญชีรับเงิน และผู้บันทึก "อื่นๆ" ให้ (ข้อมูลและค่าที่มีอยู่ไม่ถูกทับ)

**สถานะเงิน (คอลัมน์ Q) คิดให้อัตโนมัติ**

| ชำระแล้ว | สถานะ |
|---|---|
| ยังไม่ใส่ยอดรวม | ยังไม่ใส่ยอด |
| 0 | รอมัดจำ |
| มากกว่า 0 แต่ไม่ถึงมัดจำ | จ่ายบางส่วน |
| ถึงยอดในช่อง **มัดจำ (Y)** (ถ้าว่าง ใช้ % มัดจำ ค่าเริ่มต้น 50%) | มัดจำแล้ว |
| เท่ากับหรือมากกว่ายอดรวม | ชำระครบ |

**สีเตือนในแท็บการจอง**
- **แถวสีแดงที่คอลัมน์ ห้อง/วันที่** = ห้องนี้ถูกจองซ้อนกับแถวอื่นในคืนเดียวกัน หรือวันเช็คเอาท์ไม่หลังวันเช็คอิน → ตรวจและแก้ทันที
- **แถวตัวอักษรจางมีขีดฆ่า** = ยกเลิกแล้ว

**กฎสำคัญ**
- **ยกเลิก = เลือกสถานะ "ยกเลิก"** ห้ามลบแถว (เก็บประวัติไว้ และเงินมัดจำที่ไม่คืนยังเห็นอยู่)
- **เลื่อนวัน** = แก้วันที่ในแถวเดิม แล้วจดวันเดิมไว้ในหมายเหตุ เช่น `เลื่อนจาก 25/12/2026`
- **ปิดห้อง** (ซ่อม/ญาติมาพัก) = กรอกห้อง + เช็คอิน + เช็คเอาท์ แล้วเลือกสถานะ "ปิดห้อง" (ไม่ต้องใส่ชื่อ)
- วันที่คนเก่าเช็คเอาท์ คนใหม่เช็คอินได้ (ไม่นับว่าซ้อน)
- **ห้ามสลับลำดับคอลัมน์ หรือแทรกคอลัมน์ระหว่างกลาง** ถ้าอยากเพิ่ม ให้เพิ่มต่อท้ายหลังคอลัมน์ V เท่านั้น
- จะเรียง/กรองข้อมูล ใช้ **Data → Create a filter** ได้ตามสบาย

### 3. ห้องพัก

| รหัสห้อง | ชื่อห้อง | เปิดให้จอง | หมายเหตุ | ราคา/คืน (บาท) |
|---|---|---|---|---|
| R1 | ห้อง 1 | ใช่ | | 1,000 |

- **รหัสห้อง** ต้องตรงกับ `id` ใน `assets/config.js` ของเว็บ (R1–R5)
- **ชื่อห้อง** คือคำที่ขึ้นใน dropdown ของแท็บการจอง และในปฏิทิน
- **ราคา/คืน** ใช้คำนวณยอดรวมอัตโนมัติในหลังบ้าน (ค่าเริ่มต้น ห้อง 1–2: 1,000 · ห้อง 3–4: 1,500 · ห้อง 5: 1,000)
- **เปิดให้จอง = ไม่** → หน้าเว็บจะแสดงห้องนี้ว่า "งดให้บริการช่วงนี้" ทุกวัน
- ถ้า **เปลี่ยนชื่อห้อง** การจองเก่าที่ใช้ชื่อเดิมจะไม่ขึ้นในปฏิทิน ให้แก้ชื่อในแท็บการจองตามด้วย
- ถ้า **เพิ่มห้องใหม่** ให้รัน `setup` อีกครั้ง (เมนู 🏠 โฮมสเตย์ → ติดตั้ง / ซ่อมชีต) ปฏิทินจะเพิ่มบรรทัดให้

### 4. ตั้งค่า

- **B2 มัดจำ (%)** ใช้คำนวณสถานะเงิน
- **ราคาเตียงเสริม/คืน** (ค่าเริ่มต้น 200) และ **ราคาหมูกระทะ/ชุด** (ค่าเริ่มต้น 300) ใช้คำนวณยอดในหลังบ้าน
- **บัญชีรับเงิน** เช่น `ธ.กสิกรไทย 123-4-56789-0 ชื่อบัญชี ...` แสดงในข้อความยืนยันและบิลตอนรอชำระมัดจำ (เว้นว่าง = ไม่แสดง)
- **รหัสเข้าหลังบ้าน** รหัสเข้าหน้าเว็บหลังบ้าน ค่าเริ่มต้น `1234` **ต้องเปลี่ยน** แก้แล้วมีผลทันที (ดู [admin.md](admin.md))
- **คอลัมน์ D ช่องทางการจอง · E ผู้บันทึก · F สถานะการจอง** = ตัวเลือกใน dropdown เพิ่ม/ลบได้
  - **ห้ามเปลี่ยนคำว่า "ยกเลิก" และ "ปิดห้อง"** ระบบใช้คำนี้คำนวณห้องว่าง

### 5. วิธีใช้

สรุปวิธีกรอกแบบสั้น สำหรับเปิดดูในมือถือ

## ใช้ในมือถือ

ติดตั้งแอป **Google Sheets** แล้วเปิดชีตนี้
- ดูปฏิทิน: แท็บ ปฏิทิน (เลื่อนซ้าย-ขวาได้)
- กรอกการจอง: แท็บ การจอง → แตะช่องว่างแถวล่างสุด
- เลือกวันที่: แตะช่องวันที่ 2 ครั้ง จะมีปฏิทินให้เลือก

## รันซ้ำ setup ได้ไหม

ได้ ข้อมูลการจอง ห้องพัก และตั้งค่า **ไม่หาย**
สิ่งที่ถูกสร้างใหม่: แท็บปฏิทิน แท็บวิธีใช้ หัวคอลัมน์ สูตร สี และ dropdown ของแท็บการจอง
ใช้เมื่อ: เพิ่มห้อง, มีคนเผลอลบสูตร/สี, หรืออัปเดตโค้ดเวอร์ชันใหม่

## ปัญหาที่อาจเจอ

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| พิมพ์วันที่แล้วขึ้นกรอบแดง "invalid" | ต้องพิมพ์แบบ วว/ดด/ปปปป ปี ค.ศ. เช่น `25/12/2026` (ไม่ใช่ 2569) |
| วันที่สลับวันกับเดือน | ชีตยังไม่ได้รัน setup (setup ตั้งภาษาชีตเป็นแบบ วว/ดด/ปปปป ให้) |
| ปฏิทินไม่ขึ้นการจองที่เพิ่งกรอก | ตรวจว่าเลือก **ห้อง** จาก dropdown และใส่วันที่ครบทั้ง 2 ช่อง |
| ไม่มีเลขที่จองขึ้น | เลขที่จองเติมเมื่อแก้แถวผ่านหน้าจอ ถ้าวางข้อมูลหลายแถวพร้อมกันจะเติมให้ทุกแถว ถ้ายังไม่ขึ้น ใส่เองได้ |
| ช่องในปฏิทินขึ้น `#ERROR!` หรือ `#NAME?` | มีคนแก้สูตร ให้รัน setup อีกครั้ง |
