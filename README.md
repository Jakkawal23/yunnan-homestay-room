# yunnan-homestay-room

เว็บไซต์ห้องพัก **ยูนนานโฮมสเตย์** ใจกลางชุมชนจีนยูนนาน ดอยอ่างขาง จังหวัดเชียงใหม่
ดูรูปห้องพัก ราคาเริ่มต้น รายละเอียดการเข้าพัก แผนที่ และกดไปหน้าจองออนไลน์ (Google Apps Script)

เว็บเป็นไฟล์ HTML ไฟล์เดียว ไม่ต้อง build เน้นเปิดบนมือถือ

## โครงสร้าง

```
index.html                  หน้าเว็บทั้งหมด (แก้ข้อมูลที่ส่วน CONFIG ในแท็ก <script>)
images/
  hero.jpg, hero-small.jpg  รูปหน้าที่พัก (พื้นหลังหน้าแรก)
  room_01 … room_05/        รูปห้อง 01–05.jpg (01 = หน้าปก) + small/ รูปเล็ก
  common-hall.jpg           ห้องโถงส่วนกลาง
  night-street.jpg          บรรยากาศกลางคืนในชุมชน
  small/                    รูปเล็กของสองรูปด้านบน
```

ไฟล์ต้นฉบับขนาดใหญ่เก็บไว้ในโฟลเดอร์ `originals/` บนเครื่อง ไม่ได้อัปโหลดขึ้น GitHub

## แก้ข้อมูล

เปิด `index.html` แล้วแก้ในส่วน `CONFIG`:

- `rooms` ชื่อห้อง ราคาเริ่มต้น (`from`) จำนวนผู้เข้าพัก รูปห้อง
- `checkIn` / `checkOut` เวลาเข้า-ออก
- `bookingUrl`, `line`, `facebook`, `phone` ลิงก์จองและช่องทางติดต่อ
- `mapQuery` / `mapLatLng` หมุดแผนที่
- `spaces`, `highlights` รูปบรรยากาศ

## ดูบนเครื่อง

เปิดผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ที่ root ของโฟลเดอร์นี้ เช่น

```bash
npx serve .
```
